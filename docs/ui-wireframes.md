## Guided Sync Modal

```text
Step 1/4 • Read from target
Approve the initial read
Approve the read on your Ledger. The phone only reads identifier metadata
so it can compare local and device state.

[ progress bar ]
```

```text
Step 3/4 • Write merged identifiers
Approve the write
Approve the write on your Ledger. The merged identifier list will be
saved to the device.
```

```text
Step 4/4 • Finished
Synchronization complete
Local and target now share the merged vault.
[ Close ]
```
